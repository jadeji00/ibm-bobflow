# bob_sessions/

**Required deliverable.** This folder must contain Bob task session summary
screenshots as evidence of IBM Bob usage.

Every participant must upload all relevant Bob task session summary screenshots
for the project. For a solo submission, that means only this participant's
screenshots are required.

## How to capture a screenshot

1. In Bob IDE's chat interface, select **Tasks** to display the task list.
2. Select a task related to the project submission — it opens in the chat panel.
   Confirm you are in the correct project workspace. If the submission spans
   multiple workspaces, select **All** to view tasks across relevant workspaces.
3. Select the **task header**. A task session consumption summary is displayed.
4. Screenshot the summary. **PNG** is preferred for text clarity.
5. Repeat for every task related to the project submission.

## Naming convention

```
<team-or-user>_task<NN>_<short-description>_summary.png
```

Example: `teamalpha_task01_login_flow_summary.png`

## Checklist

- [ ] Every task relevant to the submission has a screenshot
- [ ] Filenames are descriptive and follow the convention above
- [ ] All screenshots are PNG
- [ ] No credentials or secrets are visible in any screenshot
